## 📊 How It Works

### Debate Flow
```
1. User Setup
   ↓
2. Topic Selection → Choose Pro/Con stance
   ↓
3. Debate Room → Timer starts (90 seconds)
   ↓
4. User speaks → Live transcription → Submit
   ↓
5. Scoring → Calculate user's score
   ↓
6. AI Response → Generated by GPT-4 → Spoken aloud
   ↓
7. AI Scoring → Calculate AI's score
   ↓
8. Next Round → Repeat steps 3-7
   ↓
9. Summary → Winner, insights, analysis
```

### Scoring Algorithm

**Relevance (35 points)**
- Keyword matching with topic
- Contextual alignment
- Topic-specific vocabulary

**Strength (40 points)**
- Minimum word count (substance)
- Evidence indicators: "research shows", "studies indicate"
- Logical connectors: "however", "therefore", "moreover"
- Argument coherence

**Engagement (25 points)**
- **Time Management** (15 pts):
  - Optimal: 45-75 seconds = 15 points
  - Good: 30-45 or 75-90 seconds = 10 points
  - Poor: <30 or >90 seconds = 5 points
- **Clarity** (10 pts):
  - Word complexity balance
  - Vocabulary sophistication

## 📡 API Endpoints

### REST API
- `GET /api/debates/topics` - Get all topics
- `POST /api/debates/create` - Create debate session
- `GET /api/debates/:id` - Get debate details
- `POST /api/debates/:id/argument` - Submit argument

### WebSocket Events
- `join-debate` - Join debate room
- `user-speaking` - User started speaking
- `user-stopped-speaking` - User stopped
- `transcription-update` - Live transcript
- `ai-response` - AI's response
- `ai-thinking` - AI processing
